# 🚀 mixed-programming

This repository is a collection of my programming ventures over the years, covering various languages, projects, prototypes, and competitive programming challenges. It serves as a personal archive of my learning journey, experimentation, and practice across multiple programming paradigms.

## 📌 What's Inside?

- **Competitive Programming** – Solutions to algorithmic problems, coding challenges, and problem-solving exercises.  
- **Language Learning** – My journey through different programming languages, including syntax exploration and practice exercises.  
- **JavaScript Prototypes** – Small projects, experiments, and snippets to understand JavaScript better.  
- **HTML & CSS Experiments** – UI prototypes, styling practices, and layout explorations.  
- **Python Scripts** – Utility scripts, problem-solving, and automation experiments.  
- **C++ Implementations** – Data structures, algorithms, and competitive programming solutions.  
- **Miscellaneous Practices** – Any other programming-related tinkering and side projects.  

## 🛠️ Languages Covered

- 🟦 **C++** – Competitive programming, data structures, and algorithms.  
- 🟨 **JavaScript** – Frontend and backend experiments, including small projects.  
- 🐍 **Python** – Scripting, automation, and learning exercises.  
- 🎨 **HTML & CSS** – Web design experiments and UI prototypes.  
- 🌱 **Others** – Any new language or framework I explore along the way.  

## 🎯 Purpose

This repository isn't about polished production code—it's about **learning, experimenting, and growing** as a programmer. Whether it's solving algorithmic problems, picking up a new language, or building quick prototypes, everything goes here as a way to document my progress.

Feel free to explore, learn from my mistakes, or even suggest improvements! 🚀
